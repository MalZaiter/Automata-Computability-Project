# DFA over {0,1} — 1s divisible by 3 and ends with 0

Constructs and simulates a DFA that accepts binary strings where the number of `1`s is divisible by 3 **and** the string ends with `0`.

## How to Run

```bash
javac Main.java
java Main
```

## Description

- Input: Binary string over {0,1}
- Output: Accept / Reject with state transition visualization
